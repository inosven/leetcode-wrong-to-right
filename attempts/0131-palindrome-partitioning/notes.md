# LC 131 Palindrome Partitioning

## 2026-11-19 · B · 15min

- 层级：实现错（老毛病：递归传固定参数）。`bt(start+1)` 应为 `bt(i+1)`。
- 反例 "aa"：切下 "aa" 后 bt(1) 又切一个 "a"，得到 ["aa","a"]。
- invariant：bt(start) 表示 s[0:start] 已切好；本层切 s[start:i+1]，下一层从 i+1 开始。
- 口诀：切到哪，下一层就从哪的下一位开始，传 i+1，不传 start+1。

## 2026-11-21 · B · 15min

- 唯一的错：提交时忘了调用 `bt(0)`（贴上来的是补上后的版本）。上次的 `bt(start+1)` 这次写对成 `bt(i+1)`。
- 复杂度：时间 O(n·2^n)（最多 2^(n-1) 种切法，每种拷贝/判回文 O(n)），空间 O(n) 递归栈 + path（不计输出）。
- 改进：先用 DP 预处理 `isP[i][j] = s[i]==s[j] and isP[i+1][j-1]`，判回文变 O(1)；最坏复杂度同阶，但重复判断少很多。
