# LC 227 Basic Calculator II

## 2026-11-27 · B · 20min（用 224/772 的双栈通用写法）

- 层级：实现错 ×4，三处是 11-19 / 11-20 的复发。
- Bug 1（复发 11-19）：读多位数 `i+1 < n-1` 应为 `i+1 < n`。"12" → 2。
- Bug 2（变量名混淆）：`nums*10` 应为 `num*10`（列表重复 → TypeError）。
- Bug 3：')' 分支算完没 `ops.pop()` 弹出 '('。
- Bug 4（复发）：运算符分支用 if 而非 while、缺 `ops and ops[-1] != '('` guard、漏 `ops.append(c)`。官方示例 "3+2*2" → IndexError。
- 口诀：查表前先确认 key 一定在表里；运算符来了，先把栈里优先级不低于它的都算掉，再把它自己入栈。
- 复杂度：O(n) / O(n)。改进：227 无括号 → 单栈写法（按前一个运算符处理数字，最后求和）。
- 数据放大：一遍扫描不怕长；深括号时迭代双栈比递归稳（递归深度上限）。
