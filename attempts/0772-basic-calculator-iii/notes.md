## 2026-11-19 · C · 30min（两题共用一份双栈代码）

- 层级：实现错 ×4，双栈 + 优先级思路对。
- Bug 1：读多位数 `while i+1 < n-1` 应为 `i+1 < n`，漏最后一位。反例 `"12"` → 2。
- Bug 2：循环体 `int(s[i])` 应为 `int(s[i+1])`，判断的和使用的不是同一个字符。只修 Bug 1 时 `"12"` → 11。
- Bug 3（guard 缺失，老毛病）：`while ops and priority[s[i]] <= priority[ops[-1]]` 栈顶是 `'('` 时 KeyError，加 `ops[-1] != '('`。反例 `"(1+2)"`。
- Bug 4：一元负号 `i-1 > 0` 应为 `>= 0`。反例 `"(-1)"`（'(' 在下标 0）→ IndexError；`"1-(-2)"` 能过。
- invariant：不越过 '(' 时 ops 从底到顶优先级严格递增；'(' 把栈分成独立的段。
- 改完与 eval 随机对拍 3000 条一致。
- 口诀：查表之前先确认 key 一定在表里；while 判断的是哪个字符，循环体里就用哪个字符。

## 2026-11-20 · B · 15min（224/772 共用一份双栈代码，贴了两版）

- 层级：实现错。根因：该看栈顶 `ops[-1]` 的地方看了字符串 `s[i]` / `s[i+1]`。
- 第 1 版：
  - Bug 1（第一个出错点，老毛病复发）：读多位数 `while s[i+1].isdigit()` 缺 `i+1 < n`，`"1"` 就 IndexError。
  - Bug 2：运算符分支 while 后缺 `ops.append(s[i])` + `i += 1` → `"1+2"` 死循环；guard 写成 `s[i] != '('`（应为栈顶，老毛病复发），`"(1+2)*3"` KeyError；while 里多了 `i += 1`。
  - Bug 3：`)` 分支 `while s[i+1] != "("` 应为 `ops[-1] != "("`，且算的过程中 `i` 不该动。
- 第 2 版：只剩 while 条件里 `precedence[ops.pop()]`，判断时就弹栈。`"1+2*3"` → 6（'+' 丢失），`"1*2+3"` → IndexError。改 `ops[-1]`。
- invariant：s[i] 是正在读的字符，ops[-1] 是之前留下、还没算的运算符；条件只看不弹，弹交给 calstack；i 只在读字符时前进。
- 改完与 eval 随机对拍 3000 条一致（含括号、一元负号）。
- 口诀：比较看栈顶不看字符串；条件里只看不弹（`[-1]` 是看，`pop()` 是拿走）；i 只在读字符时往前走。
- 复杂度：O(n) / O(n)。
